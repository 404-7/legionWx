## 尚不能称为完整 1:1

用户确认没有 Warcraft III 客户端，地图仅保存覆盖字段，无法从本机完整核实原生继承数据。

- `hfoo`、`hrif` 等未覆盖的前摇、弹速、骰子；Rhla 基础研究费用等使用显式继承默认值，来源缺口保留在审计中。CB 的 R00D 显式字段已读取，基础费用/增量缺项仍需完整客户端数据核验。
- 已实现 16 种建造者及六组原图随机池；R00I“更换为雇佣兵建造者”的特殊流程仍未移植。
- 当前使用默认模式组合记录 AP/HG/GG/MM/CB/x3；其余原图可选模式未全部开放，不应把记录模式名称理解为所有变体已实现。
- 国王完整物品栏和一部分原生施法细节仍未移植；震荡波自动施放保留原 JASS 的自身坐标目标指令，但零距离指令在原引擎中的实际处理仍待客户端复现。
- 已接入显式施工计时及取消退款；原版施工动画、地形寻路/树木阻挡、转身和原引擎内部锁敌仍不是 Warcraft 原生实现。网页导航与道路绘制共用路网，布兵格子按最新要求收进路面。
- 2D 单位素材不能替代原图全部 3D 模型、动作、粒子与音效。

这些是仍未完成的移植或核验项，不是继续保留旧用户定制的理由。后续工作仍以原图为目标，不回退到旧定制规则。
