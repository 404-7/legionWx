# 移动守军、锁敌与仇恨

## 原地图依据

来源为用户提供的 3.41 未保护地图，仅静态读取 JASS 和单位对象数据。

- 单位 `umvs` 与 `uacq` 分别提供移动速度和主动索敌范围；导入到 `UNITS.speed` / `UNITS.acquireRange` 时使用现有的 0.25 世界比例。缺少自定义 `uacq` 的兵种采用明确的网页版默认值：近战 500、远程 650（缩放前）。攻击前摇来自对象字段 `udp1`，缺少时默认 0.3 秒。
- `Trig_Create_Fighters_JASS` 在建筑位置创建战斗单位；原脚本将移动速度设为零的调用处于注释中，战斗单位并非固定炮塔。
- `Unpause_Fighters` / `Fight_Startd_Events` 注册 `EVENT_UNIT_ACQUIRED_TARGET`，发出 `851983`（attack）指令，目标为对应玩家的进军位置。
- `Trig_Antistuck_Ability_Area_Func003A` 与 `Trig_PERIOD_Antistuck_*` 对脱离指令的守军、怪物重新下达进攻路径点或王城指令。

上述脚本会调用 Warcraft 原生寻敌、移动、碰撞和攻击系统。脚本没有完整定义原生引擎的仇恨公式、锁敌时间或追踪超时，因此下列时限与评分是网页版的可调实现，不能称为原版逐值复刻。

## 网页行为规则

兵的原始格子 `col / row` 保留为建造位置，战斗位置 `x / y` 独立移动。服务器与单机共同加载 `js/behavior.js`，在线客户端不计算移动和仇恨。

| 项目 | 当前规则 |
| --- | --- |
| 主动接敌 | 仍有怪物待出场时，未接敌的守军可向来怪方向前移最多 120 世界像素；仍受防区范围限制 |
| 扫描间隔 | 0.2 秒，目标死亡或被移除时立即重扫 |
| 最短锁敌 | 0.65 秒，避免最近目标轻微变化时不断换怪 |
| 追踪丢失 | 目标超过约 1.8 倍索敌距离后保留 1.25 秒；越过追击边界则放弃 |
| 最长追击 | 尝试追击累计 8 秒，走不动也计时；连续 1.25 秒无进展则提前放弃目标；进入攻击距离后清零，不限制正常持续交战 |
| 追击边界 | 守军距原阵位 440 像素；怪物距本次接敌位置 280 像素；PK 不使用守关阵位距离限制 |
| 回阵与忽略 | 追击失败后回阵，暂不主动接新目标；原目标忽略 2 秒，最短重新接敌冷却 0.9 秒 |
| 攻击 | 近战接近目标，远程进入射程后停住；普攻经前摇后结算，前摇中目标死亡或移出射程会取消；纯法术兵按法术范围接敌 |
| 受伤仇恨 | 实际伤害产生仇恨，最多记入单次 120 伤害；条目上限 15，4 秒后过期并持续衰减 |
| 治疗仇恨 | 有效主动治疗的 25% 按受伤仇恨规则计入，只有距被治疗者 220 像素内的敌人受到影响；过量治疗不计入 |
| 换目标 | 锁敌期后，候选目标的距离与仇恨综合评分需超过当前目标约 45% 才切换；不是强制嘲讽 |
| 减速与定身 | 移速乘以当前减速倍率；定身不移动，眩晕不移动、不普攻或主动施法 |

## 行走范围、漏怪与结算

守关期间可走区域为同阵营两条布阵防区、对应的纵向进军道路、中央阵营支路和本队王城支路。直线被矿区或非通行地形挡住时，通过道路节点绕行，不穿越经济矿区、河道或关闭的中央关门。PK 则沿既有进场路线过桥，抵达交战区后使用同一锁敌与攻击逻辑。

漏怪进入王城支路后可被同阵营两路守军共同攻击，也会对附近同阵营守军产生仇恨；持续伤害、回血与光环仍由原防区单独推进一次，避免共享目标重复结算；超出追击时间或距离的守军返回原阵位。怪物脱战后继续进军，不因丢失目标停在原地。守军或国王击杀怪物时，赏金按拥有该怪物的防区结算且只支付一次。

轻量单位分离减少重叠，不采用完整 Warcraft 寻路网格或物理引擎。战斗结束后永久兵满血回到建造格子，清除目标、仇恨、前摇和追击状态；临时召唤物清除。战斗中点击兵的实际位置查看详情，经济操作仍用原始格子标识单位。

## 道路表现

道路使用带石质路沿的石板纹理与圆角转弯，阵营颜色改为嵌入路面的方向路标。中央河道通过石桥连接，桥头有双方旗帜和石塔；关门平时合拢，PK 时门扇缩回上下塔侧，取代之前的绿色方框。门的动画状态仅存于浏览器渲染层，不参与服务器模拟。

道路网络按材质统一分层：先绘制全部阴影，再绘制全部路基、路沿和铺装，T 字路口不会出现支路端头的边缘覆盖主路路面。石桥只在南北两侧绘制护栏与阴影，东西入口与连接道路保持贯通。

行为验证见 `tests/behavior.test.cjs`，移动单位点击与手机交互见 `scripts/movement-smoke.cjs`，道路和 PK 桥门流程见 `scripts/map-arena-smoke.cjs`。

## T 字汇合卡怪修复

已复现的原因是：王城支路上的怪物可以锁定另一条己方防区的战士，但旧可走区域只包含怪物原属防区；路径回退到当前位置后无法前进，而追击计时仅在移动成功时增加，最终永久停在汇合口。

现在同阵营两片防区共用合法通行范围；无法抵达且不在射程内的目标不会被怪物锁定。追击时间按尝试时长推进，连续无进展 1.25 秒会忘记目标并恢复路线。道路、矿区与中央关门的阻挡约束仍有效。攻击距离额外使用 0.1 世界像素的浮点容差，避免到达射程边缘却持续判为“尚未进入射程”。

`tests/junction-sale.test.cjs` 覆盖红蓝四路跨防区追击、无进展脱离、不可达目标、射程边界、144 怪物双路汇合与共享目标只结算一次的情况。
