# 3.41 数据与复刻范围

本次以用户提供的 `3.41 stats 2011-10-25.xls` 和 `Legion TD Mega 3.41 unprotect.w3x` 为来源。没有使用同文件夹中的 3.5 B4 地图替代 3.41。读取地图仅解析对象数据和 JASS 文本，不执行其中的脚本。

## 已接入的数据

- 原表 `Unit stat` 的全部 187 行：14 种族、84 个基础兵、98 个进阶或姿态单位、5 个表内召唤物。保留英文名、原表行号、Cost、Total、人口、原始射程、攻击间隔、最小/最大攻击、表列 DPS、生命、攻击和护甲类型。
- 由地图 592 个单位对象解析建筑与战斗单位的对应关系、真实升级分支、姿态、护甲值、生命恢复、法力和技能引用。额外读取地图内召唤物和驾驶员，不能直接购买。
- 由 442 个技能对象和相关 JASS 触发器转换治疗、光环、暴击、闪避、重击、毒伤、减速、减甲、法力护盾、主动法术、召唤、幻象、范围攻击、死亡效果等网页战斗逻辑。原始技能字段与说明仍保留在生成数据中。
- 原表 `Level Bounty` 的 31 波数量、赏金、奖金和推荐战力；怪物属性来自对应地图对象。第 10、20、30 波各三个首领，第 31 波无赏金和奖金。`Total Gold` 是预算参考，不是每波额外发放的金币。

## 取值规则

表格数值优先。与地图有 9 处 Cost 差异；另有 5 处 Total 不等于前置 Total 加 Cost，详见 `data/legion341-map.json`。购买、升级按 Cost 收费；Total 保留作图鉴参考，出售按实际投入计算，避免利用总价差异套利。原表空白的召唤物属性从地图补齐。

原表 Speed 是攻击间隔（秒），不是移动速度。普通攻击在 Min–Max 之间取值，DPS 原值用于图鉴核对。Warcraft 距离以 0.25 比例映射到画布；图鉴仍显示原始射程。护甲类型倍率与护甲值减伤分别计算，法术伤害与魔法普攻分开。

## 网页版规则与精确还原的边界

本项目仍是服务器权威的 2v2 网页塔防，保留玩家提出的经济金矿、国王三项强化、单机 AI 和在线房间。基础持续收入仍为每波 6 金，因此有额外收入时预算不会恰好等于原表 Total Gold。

兵种属性与升级树已逐行核对，技能按网页引擎适配。战士在格子上战斗，使用网页索敌和碰撞；没有移植 Warcraft 的移动单位寻路、施法前后摇、逐帧攻击事件和原版三维模型文件/音效。范围法术使用圆形目标筛选，部分原版扇形、弹跳轨迹、溅射层级和隐藏默认参数采用简化逻辑；没有经过 Warcraft 客户端逐技能对照测试，不能将本版称为原引擎 1:1 仿真。

变异体注射在准备阶段手动购买，生命 +20%、攻击 +25%，持续下一波；因网页版没有木材系统，将原版的 50 木转换为 50 金，并在按钮上明示。底栖兽和巨钳之王按技能返还实际投入的 90%；其他单位保留网页版全额出售规则。阵亡建筑兵不会永久消失，下一波满血复活；临时召唤物会清除。

## 可追踪与重建

- `data/legion341-sheet.json`：只读导出的原表值与 SHA-256。
- `data/legion341-map.json`：对象数量、建筑对应关系及冲突记录。
- `data/legion341-audit.json`：每个兵种的来源行、对象 ID、升级分支和技能适配项。
- `js/source341.js`：浏览器与服务端共用的生成数据。
- `scripts/import341-sheet.py`：用 xlrd 只读导出工作簿。
- `scripts/inspect-map341.py`：用 mpyq 只读解包地图。
- `scripts/build341.cjs`：从导出值与地图对象生成运行数据。
- `scripts/audit341.cjs`：生成技能与来源审计表。

Python 提取器需要 `xlrd==2.0.2`、`mpyq==0.2.5`；可安装到临时目录 `%TEMP%/legion-xls-reader`，不属于游戏运行依赖。从项目根目录依次执行：

```powershell
python scripts/import341-sheet.py '原表路径.xls'
python scripts/inspect-map341.py '3.41地图路径.w3x'
node scripts/build341.cjs
node scripts/audit341.cjs
npm test
```

地图解包文件留在忽略目录 `.cache/source341/`；不把原地图或用户下载目录整体加入 Git。游戏运行只需要已经生成的 JavaScript 数据，不需要 Python、Excel 或 Warcraft。

兵种外观现使用经典模型的二维展示资源，保留地图配色；自定义模型的近似替代详见 `assets/unit-art/mapping.json`，来源见 `assets/unit-art/README.md`。
