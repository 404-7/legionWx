# Legion TD 3.41 网页移植

规则以用户提供的 **Legion TD Mega 3.41 unprotect.w3x** 为准；此前金矿、三折退款、自定义 2v2 地图等玩法已撤销。当前仍有未移植及未核验内容，不能称为已经验证的 1:1 复刻，详见 [当前规则与剩余边界](docs/native341.md)。

支持 Node 服务端权威联机、原图八席容量及单人练习；空席位不自动填 AI、不刷怪。保留手机横屏操作和卡片式界面。

地图按最新要求保留一个例外：怪物沿道路持续走到国王，取消漏怪传送；加宽路面，18×25 格防区仅覆盖道路，城镇位于防区之外。

## 启动

需要 Node.js 22 或更新版本，无第三方运行依赖。

```powershell
$env:HOST='0.0.0.0'
$env:PORT='3001'
npm start
```

电脑打开 http://localhost:3001，手机在同一局域网打开电脑局域网 IP 的 3001 端口。联机最多八名实际玩家，西/东两队各四席；AP 在进入地图后选择建造者，CB 允许按规则研究更换，已有军团保留。

## 当前规则

- 开局 300 金、97 木、一名伐木工、0 收入；金币和木材分别支付，不作兑换。
- 伐木工 50 金、30 秒训练，初始上限七名；采木研究读取原图费用、时间和等级。
- 初始人口 15，农场按原图金木费用扩容，最多 200。
- 出售按物编点数价值；新建未参战 100%、普通 50%、特定兵种 90%，战斗中不能出售。
- 兵种属性和价格以物编优先，表格值留在来源记录；不再用表格覆盖地图冲突值。
- 第 10、20 波后传送独立竞技场，按原图准备、倒计时、发奖与结果展示流程继续守关。
- MM 隐藏整个敌方区域；GG/HG 使用漏怪赏金折扣和国王电脑金币奖池。
- 永久建筑与战斗副本分离；空席或离场玩家停止后续刷怪。
- 16 种建造者，包含 Hybrid 随机建造、Prophet 随机牌组及重抽；施工计时与取消退款读取地图。
- 国王支持控制权、手动选敌、技能指令及建造者一次性 Holy Light。

## 验证与重建

```powershell
npm test
node scripts/build341.cjs
node scripts/audit341.cjs
node scripts/audit-weapons341.cjs
```

数据重建需要已提取的 .cache/source341/ 原始地图文件。游戏运行只需要仓库里生成的 js/source341.js，不依赖 Python、Excel 或 Warcraft 客户端。

Docker 可用仓库内 Dockerfile 与 compose.yaml 部署。当前仅本地 Git 管理，未推送远程仓库。历史自定义规则测试在 tests/legacy-custom/ 留档，当前验收以根目录原版测试为准。
