# 军团战争 · Legion Arena

统一战场的 2v2 自走棋塔防。支持离线单机与 2–4 人真实在线对战，空位由 AI 补齐。无第三方运行时依赖，需要 Node.js 22 或更新版本。

## 本地运行

```sh
npm start
```

打开 http://localhost:3000 。在线对战时创建房间，将邀请链接或六位房间码发给朋友；至少两名真人连接后，房主可以开始。加入顺序是蓝方一号、红方一号、蓝方二号、红方二号。

只玩单机也可直接打开 `index.html`，不依赖服务器和外网。

## 远程部署

将整个项目上传服务器，任选一种方式启动：

```sh
# Node.js
npm start

# 或 Docker Compose
 docker compose up -d --build
```

默认监听 `0.0.0.0:3000`，通过服务器 IP 的 3000 端口访问。部署环境可使用 `PORT`、`HOST` 环境变量修改监听地址。云服务器需在安全组放行对应端口；域名部署可反向代理到该端口。Node 启动方式需由系统服务或进程管理器保活；Compose 已配置自动重启。

Nginx 反向代理示例（放入已有 HTTPS server 配置，证书按自己的域名配置）：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $http_host;
    proxy_set_header Connection "";
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 3600s;
}
```

`/api/events` 使用 SSE 长连接。代理必须关闭缓冲，避免战场状态延迟。操作通过同源 HTTP POST 提交，健康检查地址为 `/healthz`。Docker 镜像使用非 root 用户，并包含健康检查。

当前房间保存在单进程内存中：服务器重启会结束现有房间。部署一个实例即可；多实例需要将同一房间固定到同一进程。本版包含房间邀请与对战，不含账号、排行榜、公网匹配或跨重启存档。尚未做大规模并发容量测试。

## 地图和操作

在线创建房间时可选择「随机种族」或「自选种族」。随机模式在开局时由服务器为全部真人与 AI 各分配一个种族；自选模式要求每位真人先在战备大厅选择种族，允许双方或队友同族，空位 AI 自动分配。房间模式由创建者确定，加入者沿用该设置。

开局后每个席位整局只可建造本族兵种，商店仅展示该族的基础兵与完整图鉴，合法升级、形态切换和技能召唤照常生效。服务器拒绝跨族购买和开局后改族；种族随对局状态同步，刷新、断线重连、波次结算和 PK 均不会重新抽取。经济金矿、国王强化和中立雇佣兵不受种族限制。单机保留现有的全种族混编玩法。

### 种族兵营

兵营按用户提供的 **3.41 原版兵种表与未保护地图**导入全部 **14 种族、187 条兵种记录**，包含 84 个基础兵、98 个进阶或姿态单位和 5 个表内召唤物。商店支持种族分页和完整图鉴，可查看中文名、英文名、原表行号、生命、攻击区间、攻击间隔、原始射程、人口与技能说明。升级路线取自原地图，支持多级、多分支和英雄之魂免费切换姿态。

购买和升级按表格 Cost 收费，Total 仅作原表总价参考；两列不一致时不会用总价差代替实际升级费用。表格与地图的价格冲突已记录在 data/legion341-map.json。所有属性均保留来源，重建流程和网页版规则差异见 [3.41 数据说明](docs/source341.md)。原表全部 31 波的数量、赏金和奖金已接入，怪物属性来自地图。击杀发放赏金、波次结束发放奖金，Total Gold 不重复发放；既有持续收入和经济金矿另行计算。

已接入治疗、攻击与护甲光环、吸血、毒伤、控制、主动施法、召唤、幻象、护盾、九头蛇分裂、奴隶贸易、驾驶员脱离等效果。阵亡兵下波满血复活，临时召唤物在波次结束清除。技能经过网页战斗引擎适配；路径、动作时序和部分范围伤害采用简化实现，并非 Warcraft 原引擎仿真。

一张 1800×1440 地图容纳两队四个防区，每人的可建区域为 **12×16，共 192 格**。红队在左、蓝队在右，两侧怪物从上、下端向中间推进；漏怪沿本阵营路标指示的石板路转弯，再沿王城支路抵达国王。国王使用粉色圆环，红方在中上、蓝方在中下；四个灰色矩形为独立矿区。中央石桥设双塔关门，平时关闭，PK 回合缩回门扇开放。每人只能在高亮的自己的防区布阵。

守军会移动接敌和追怪，近战靠近攻击，远程进入射程后停住输出。移动速度和明确的索敌范围读取原地图；网页版另设 0.65 秒最短锁敌、1.25 秒远距追踪保留、8 秒最长移动追击，以及伤害 / 治疗仇恨、追击边界和回阵规则。守军可继续追击进入本队王城支路的漏怪，沿可通行道路绕过矿区；战斗结束恢复原格子。具体参数、原版来源与差异见 [战斗行为说明](docs/combat-behavior.md)。

按原版 3.41，在第 **10、20 波结束后**插入阵营 PK，先给 30 秒调整阵容，再让双方全部建成单位满血沿阵营路线走向中央路口交战。国王和金矿不参战，战斗期间锁定买兵、升级和出售；雇佣兵保留到下一波怪物战。兵种沿用原属性、技能、召唤和复活，全队活单位（含召唤与待复活单位）归零即输掉本回合。胜方每人获得波次×10 金，平局每人获得波次×5 金；没有击杀金币或额外波次奖金。5 秒展示结果后恢复所有永久单位的原阵型、生命与技能状态，继续第 11 / 21 波，整局仍以国王和最终波结算。180 秒未分出胜负按平局处理。来源与网页版改动见 [竞技场对照](docs/arena341.md)。

- 点击兵种卡片，再点击自己防区的格子购买；右键或 Esc 取消。
- 取消购买选择后，点击已有单位选择升级分支或卖出；战斗中需点击移动后的兵，详情显示其当前行为和移速。一般全额返还实际投入；底栖兽和巨钳之王按技能返还 90%。
- 进攻军团已按原地图扩充为 24 类，按第 1 / 10 / 15 波分组开放。双列卡片保留名称、价格、收入和两个敌军派遣按钮；点击卡片查看完整属性与中文技能。单位送往指定敌军防区，增加自己的每波收入；光环、破甲、毒伤、嗜血、吸血、魔免及弑君效果参与实际战斗。原木材费用在网页版按 1:1 金币支付，来源与适配差异见 [进攻军团说明](docs/mercenaries341.md)。
- 点击地图个人矿区的任意空矿位（＋）打开建造窗口，花 100 金在该位置购买金矿，每人最多 6 座。点击已有金矿弹窗升级，可查看当前/下级收益、费用、余额及产金倒计时。地图「矿区」按钮定位个人矿区；不占战士格子，不参与战斗，金币只归拥有者。
- 金矿共 5 级，每座每 5 秒分别产出 **8 / 12 / 18 / 26 / 36 金**，升往下一级分别花费 **80 / 120 / 180 / 260 金**。每座从建造完成起独立计时，升级保留倒计时，下次产出按新等级计算；准备和战斗均产金，暂停、在线断线暂停和结束后停止。单机倍速也会加快产金。金矿没有出售功能，跨波次保留。
- 国王分生命、攻击、生命恢复三项独立强化，等级与效果由队友共享。每级分别增加 150 生命上限（同时恢复 150 生命）、9 攻击、1 生命/秒；初始恢复为 2 生命/秒，准备与战斗期间持续生效，暂停时停止。三项起价均为 80 金，各自每级加价 40 金，每次强化仍增加操作者 2 收入。
- 单机：空格暂停，1 / 2 / 3 切换速度；在线：服务器固定 1 倍速。
- 在线断线后全局暂停，60 秒内刷新原页面可恢复原席位。凭证保存在当前标签页 sessionStorage；使用邀请链接新开页面可作为另一位玩家加入。超过重连时限或主动离开会判该玩家所在队弃权。
- 开局前离线席位保留 60 秒，超时释放；房主离开后由下一位玩家接任。
- 第 31 波后比较国王剩余生命比例，完全相同时平局。

## 架构

```text
server/index.cjs    HTTP 静态资源、房间、SSE、鉴权、限流和对局时钟
server/game.cjs     独立 VM 中复用战斗引擎，每间房隔离状态
js/source341.js    从原表和地图生成的完整数据
js/skills341.js    原版技能字段解析
js/combat341.js    主动法术、状态、召唤与专用触发器
js/config.js       地图与平衡参数
js/data.js         兵种、雇佣兵、波次
js/engine.js       浏览器单机 / 服务端在线共用战斗引擎
js/behavior.js     稳定锁敌、仇恨、移动追击、道路导航和回阵
js/ai.js           AI 补位
js/network.js      大厅、房间凭证、重连、操作分发
js/render.js       统一地图与 Canvas 战斗渲染
js/ui.js           本人席位 UI 和交互
js/layout.js       标签面板、手机抽屉、地图相机与触摸手势
js/sprites.js      程序化单位贴图
js/main.js         渲染循环；在线时禁用本地战斗模拟
```

在线客户端仅发送购买、升级、卖出、强化、雇佣等意图。服务器依据凭证确定操作者，校验金币、格子和目标；金币与胜负不接受客户端传值。服务器以 20 Hz 推进模拟，以 10 Hz 推送快照。暂离时服务器停止模拟，恢复连接后继续。

## 桌面与手机操作

桌面右侧通过「军营 / 进攻」两个标签切换操作，同一时间只显示一个面板。点击地图上的已建单位打开详情，选择升级或出售；点击己方国王打开生命、攻击、生命恢复强化弹窗，顶部己方国王血量也可快捷打开。强化费用与共享规则保持不变，联网提交期间锁定按钮等待权威状态。战场记录默认折叠。

手机以横屏游玩为主：右侧四个竖向标签打开侧滑操作面板，顶部使用紧凑状态栏，地图占用剩余整块区域。较宽的手机横屏同样采用触摸布局，不会因宽度超过 900px 切回桌面侧栏。竖屏兼容底部导航与抽屉，并显示可关闭的横屏建议；旋转不重开对局。

选兵后自动收起军营，地图底部显示待放置单位与取消按钮。手机默认放大自己的防区，支持单指拖动、双指缩放；「防区全览」查看完整的 192 格，「我的防区」恢复可触摸的大格子，「全图」查看双方战场。PK 开始会切到全图，「PK 战场」可放大中央交战区。出售单位需再次确认。暂停、倍速、帮助和重开集中在右上角「···」菜单。金矿直接点击地图操作，不设经济标签；「矿区」快速定位后点击空矿位建造、已有矿井升级。联网按钮提交后等待权威状态同步，避免重复点击。

可用 `node scripts/responsive-smoke.cjs` 运行桌面、手机竖屏、小屏和横屏的界面验证；支持传入 Playwright 包目录及截图输出目录作为两个参数。

`node scripts/map-arena-smoke.cjs` 检查新地图与阵营 PK 的准备、开门、交战、结算和回到下一关，也支持同样的 Playwright 与截图目录参数。

`node scripts/movement-smoke.cjs` 检查常规守关的移动、伤害、移动单位实时点击和手机详情操作。

`node scripts/landscape-smoke.cjs` 检查三种手机横屏尺寸、右侧操作栏、侧滑面板、旋转保留对局，以及 T 字路口路面的像素回归。

`node scripts/race-mode-smoke.cjs` 用桌面和横屏手机两个独立客户端检查房间模式、选族、单族商店、跨族购买拒绝、手机放兵和刷新后种族保持。

## 兵种外观

地图单位、商店肖像、召唤物、敌人与国王已切换为经典 War3 单位展示资源，187 条兵种记录对应 123 份本地透明贴图，并保留地图指定的配色。商店改为大肖像卡片，可直接辨认装备与种族。少数自定义模型使用相近的经典单位替代；资源来源、对应关系和重建脚本见 [美术说明](assets/unit-art/README.md)。这是一套经典模型的二维渲染贴图，不是实时三维模型；运行时不需要外网。
