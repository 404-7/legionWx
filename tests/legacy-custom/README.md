# Superseded customization contracts

These historical tests describe the former 2v2 layout, six gold mines, 30% resale, gold-only resource conversions and room-level random/select restrictions. The user explicitly withdrew those rules. They are retained for history and are not run by the root `tests/*.test.cjs` command.

Active replacements verify the native eight-slot layout, source map data precedence, lumber economy, original refunds, separate arena and authenticated online actions. King, mercenary and weapon combat regressions remain active after their resource/seat fixtures are migrated.
